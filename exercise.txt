Ex. 7 React Lab Exercise: Frame-Based Layout Using React Components 
1. Aim 
To develop a simple frame-based webpage layout using React components, consisting of a 
Header, Sidebar, Content area, and Footer. 
 
2. Objectives 
After completing this experiment, students will be able to: 
1. Create a React application using Vite. 
2. Understand the concept of a frame-based webpage layout. 
3. Create reusable React components. 
4. Divide a webpage into Header, Sidebar, Content, and Footer sections. 
5. Apply CSS to arrange React components. 
6. Understand how components work together to create a complete webpage. 
 
3. Software Requirements 
• Node.js 
• Visual Studio Code 
• React 
• Vite 
• Web Browser

6. Step 1 – Create Header Component 
Create: 
src/components/Header.jsx 
Write: 
function Header() { 
  return ( 
    <header className="header"> 
      <h1>Student Management System</h1> 
    </header> 
  ); 
} 
 
export default Header; 
The Header component displays the title of the application.

10. Step 5 – Use Components in App.jsx 
Open: 
src/App.jsx 
Replace the existing code: 
import Header from "./components/Header"; 
import Sidebar from "./components/Sidebar"; 
import Content from "./components/Content"; 
import Footer from "./components/Footer"; 
 
import "./App.css"; 
 
function App() { 
  return ( 
    <div className="app"> 
 
      <Header /> 
 
      <div className="main"> 
        <Sidebar /> 
        <Content /> 
      </div> 
 
      <Footer /> 
 
    </div> 
  ); 
} 
 
export default App;

14. What is a Frame-Based Layout? 
Traditionally, HTML used <frameset> and <frame> to divide a browser window into different 
sections. 
For example: 
Header 
────────────── 
Sidebar | Content 
────────────── 
Footer 

Modern React applications generally do not use HTML <frame> or <frameset>. 
Instead, React uses: 
Components 
    + 
CSS Flexbox/Grid 
    + 
React Router when navigation is required 
This gives a similar visual layout while keeping the application component-based.

17. Viva Questions 
1. What is a React component? 
A component is a reusable building block of a React user interface. 
2. Can we use <frame> in React? 
Technically HTML elements can be written, but the old <frame>/<frameset> approach is obsolete 
and is not used for modern React layouts. 
3. How can we create a frame-like layout in React? 
We can use React components together with CSS Flexbox or CSS Grid. 
4. What is the purpose of App.jsx? 
App.jsx acts as the main application component and can combine other components. 
5. What is Flexbox? 
Flexbox is a CSS layout mechanism used to arrange elements in rows or columns. 
6. Why are components useful? 
Components make an application easier to organize, reuse, maintain, and develop.
